Plugins (PLUGINS)
The ordered plugin chain, as JSON plugin specs [{"name": "…", "params": {…}}]. Pick a built-in, fill in its params (the hints show each param's default and allowed values). When non-empty this takes precedence over the Prefilter section above (the proxy then ignores the legacy settings) and request_log here wins over the Request log toggle.
Plugins run in list order; the first that responds ends the chain. Unknown names abort startup with a precise error.
